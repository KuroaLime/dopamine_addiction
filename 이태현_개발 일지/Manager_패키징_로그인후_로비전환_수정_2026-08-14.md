# Manager 패키징 로그인 후 로비 전환 수정

## 확인된 증상

- 패키징 클라이언트에서 로그인 버튼을 누르면 로그인 화면에 머물렀다.
- IOCP 로그에는 `LOGIN -> ID_NOT_FOUND -> REGISTER OK -> LOGIN OK`가 기록됐다.
- 따라서 TCP 연결, 인증 패킷 송수신, 자동 회원가입 및 재로그인은 정상이며 실패 지점은 로그인 성공 후 로비 맵 로드 단계다.

## 원인

- 로그인 성공 처리에서 `OpenLevel`에 짧은 이름 `Lobby_Stage`를 전달했다.
- 에디터에서는 짧은 이름 검색이 성공할 수 있지만 Cook된 패키지에서는 전체 패키지 경로로 해석되지 않을 수 있다.
- `DefaultGame.ini`에 명시적인 `MapsToCook` 목록이 없어 동적 이름으로 불러오는 로비 및 카드 레벨의 Cook 포함 여부도 보장되지 않았다.

## 반영 내용

- 로그인 성공 시 `/Game/Lobby/System/Lobby_Stage` 절대 경로를 사용하도록 변경했다.
- `DefaultGame.ini`의 패키징 설정에 다음 맵을 명시했다.
  - `/Game/Login/Login_Stage`
  - `/Game/Lobby/System/Lobby_Stage`
  - `/Game/InGame/System/Main_Game_World`
  - `/Game/InGame/System/Card_Game_Stage`

## 검증 기준

1. IOCP에 최종 `LOGIN ... result=OK`가 기록된다.
2. 패키징 클라이언트가 로그인 화면에서 로비로 전환된다.
3. 방 시작 후 `Main_Game_World`로 접속한다.
4. 카드 단계 전환 시 `Card_Game_Stage`가 정상 로드된다.

빌드 및 재패키징은 이 수정 작업에서 실행하지 않았다.

## 1) 배경 / 목표
- 배경: 지난 작업으로 방 입장/퇴장 로직은 완성되었으나, 실제 게임이 실행될 Dedicated Server(DS)로 유저들을 보내주는 연결 고리가 없었음.
- 목표:
  - (1) 로비 서버가 사용 가능한 DS 포트 목록을 관리하고,
  - (2) 방이 꽉 차면 빈 포트를 할당해서,
  - (3) 유저들에게 "이 IP와 포트로 이동하라"는 명령을 내리는 것.

---

## 2) 작업 상세

### 2-1. DS 포트 관리자 (Port Manager) 구현
- 위치: `LobbyService.h/cpp`
- 구현 내용:
  - `m_freePorts` 벡터를 만들어 7777~7791번(총 15개) 포트를 초기화(`InitPortPool`) 시점에 미리 담아둠.
  - `AllocPort()`: 풀에서 포트 하나를 꺼내서 반환. (가용 포트 없으면 0 반환)
  - `FreePort(port)`: 사용이 끝난 포트를 다시 풀에 반납.

### 2-2. 게임 시작 트리거 및 할당 로직
- 위치: `LobbyService::HandleRoomJoinReq`
- 로직 변경:
  - 기존: 4명이 차면 상태만 `IN_GAME`으로 변경.
  - 변경: 4명이 차면 `AllocPort()`를 호출하여 포트를 배정받음.
    - 배정 성공 시: 방 상태 `IN_GAME` 변경 + 방 정보에 `dedicatedPort` 저장 + 멤버 전원에게 이동 명령 전송.
    - 배정 실패 시: (로그 출력 후 대기)

### 2-3. 이동 명령 패킷 구현 (Session Handover)
- Protocol: `S2C_GAME_START` (OpCode 200) 추가.
- NetApi: `SendGameStart(ip, port, ticket)` 함수 구현.
  - Payload 구조: `[IP길이(1)] + [IP문자열(N)] + [티켓(4)] + [포트(2)]`
  - 현재 IP는 로컬 테스트용 `127.0.0.1`로 고정, 티켓은 임시 `0` 사용.

### 2-4. 자원 정리 (Cleanup)
- 위치: `LobbyService::HandleRoomLeaveReq`
- 로직:
  - 방의 인원이 0명이 되어 방이 사라질 때, 해당 방이 점유하던 포트가 있다면 `FreePort()`로 반납.

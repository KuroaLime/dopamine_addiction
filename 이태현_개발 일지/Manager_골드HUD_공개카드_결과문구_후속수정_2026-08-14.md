# Manager 골드 HUD·공개 카드·섯다 결과 문구 후속 수정

- 기준일: 2026-08-14
- 프로젝트: `X:\Project\Manager`
- 성격: 기존 임시 UI의 실제 2클라이언트 화면 문제를 보정한 클라이언트 표시 패치
- 빌드 상태: 사용자 요청에 따라 이번 작업에서는 빌드하지 않음

## 1. 실제 확인된 문제

### 1.1 TPS 상단 골드 문구 넘침

- 기존 상단 `Round_Text` 한 칸에 `골드 10000 | 1위`를 함께 넣어, 고정 폭을 넘어 오른쪽 칸과 겹쳤다.
- 골드 원본 값이나 복제 문제는 아니고 표시 위치와 문자열 길이 문제였다.

### 1.2 공개 카드가 최종 2장 제출 뒤에야 보이는 것처럼 보임

- 서버 로그에서는 첫 공개 직후 이미 `Revealed=1 Submitted=0` 상태가 양쪽 클라이언트에 도착했다.
- 서버는 `SeotdaTurnOrder` 기준 절대 `SeatIndex`를 보내지만 UI는 상대 배열의 0번, 1번 순서로 좌석을 압축해 표시했다.
- 서버의 상대 배열은 자기 자신을 의도적으로 제외하므로, UI에는 자기 공개 카드를 표시할 정보가 없었다.
- 공개 카드 이미지의 상위 WBP 패널이 여러 단계 접혀 있을 때 기존 4단계 부모 표시만으로는 부족할 수 있었다.
- 따라서 서버 공개 시점이 늦은 것이 아니라 좌석 배치, 자기 좌석 복원, 부모 표시가 합쳐진 클라이언트 UI 문제였다.

### 1.3 결과 문구 `IDs: +6 +>1004`

- 서버 정산 원문은 `ID:+6=>1004`이며 뜻은 `ID가 6골드를 받아 최종 1004골드가 됨`이다.
- 기존 임시 포맷터가 모든 `=`를 ` +`로 단순 치환해 `=>`가 `+>`로 깨졌다.

## 2. 반영 내용

### 2.1 TPS 골드 HUD 이동

- 상단 바는 `등수 N위`만 표시하도록 되돌렸다.
- TPS 화면 오른쪽 아래에 기존 `/Game/InGame/UI/T_UI_Icon_Gold` 금화 텍스처와 보유 골드 숫자를 별도 Slate 오버레이로 표시한다.
- 숫자는 복제된 `AMainPlayerState::CurPlayerData.HoldingGold`만 읽으며 값이 바뀔 때만 텍스트를 갱신한다.
- 결과 오버레이보다 낮은 Z 순서를 사용하고 입력을 받지 않으므로 전투 입력과 결과창을 가리지 않는다.
- TPS HUD가 제거될 때 오버레이도 함께 회수한다.
- 섯다 화면의 기존 `InfoTxt` 골드 표시는 유지해 섯다와 배틀로얄 양쪽에서 골드를 확인할 수 있다.

### 2.2 공개 카드 즉시 표시 보정

- 상대 정보는 배열 순서가 아니라 서버가 보낸 절대 `SeatIndex`에 배치한다.
- 상대 목록에서 빠진 좌석을 로컬 플레이어 좌석으로 복원한다.
- 자기 공개 카드는 서버 ACK가 먼저 오면 로컬에서 기억한 카드 ID를, PlayerState 복제가 먼저 오면 `RevealedCard`를 사용한다.
- 공개 실패 ACK에서는 임시 카드 ID를 제거해 서버가 거부한 카드를 잘못 표시하지 않는다.
- 새 라운드 카드 인스턴스가 들어오면 공개 카드 캐시를 초기화한다.
- 공개 카드 이미지의 상위 WBP 패널을 충분한 깊이까지 표시해 최종 2장 제출 전에도 카드 앞면이 보이게 한다.
- 서버의 공개·최종 제출 RPC, 판정, 복제 필드는 변경하지 않았다.

### 2.3 섯다 결과 문구 구조화

- `Payouts`를 `플레이어:+획득액=>정산 후 보유액` 구조로 분리해 읽는다.
- 예: `IDs:+6=>1004`는 `IDs: +6골드 (보유 1,004골드)`로 표시한다.
- 동점으로 정산 대상이 여러 명이면 한 사람씩 줄을 나눠 표시한다.
- 결과창 형식은 승자, 승리 족보, 총 팟, 정산 내역 순서다.
- `GwangDdang`의 `SubRank`도 읽어 `13광땡`과 `18광땡`을 구분한다. `38광땡`은 기존 구분을 유지한다.

예상 표시 예:

```text
섯다 1라운드 결과

승자: IDs
승리 족보: 갑오
총 팟: 6골드

정산
IDs: +6골드 (보유 1,004골드)
```

## 3. 현재 조작법

### 3.1 상점

- 키: `K`
- 열기: TPS 상태이면서 서버가 `PreBattleShop` 상점 이용 가능 상태를 연 동안 `K`
- 닫기: 상점 화면에서 다시 `K`
- 전투 도중 상점 이용 가능 상태가 아니면 `K`를 눌러도 열리지 않는 것이 현재 의도된 동작이다.

### 3.2 카드 버리기

- 배틀로얄 TPS 키: `Q`
- `Q`를 짧게 눌렀다 떼면 버릴 카드 선택이 다음 카드로 이동한다.
- 선택된 카드에는 HUD 하이라이트가 표시된다.
- `Q`를 0.6초 이상 누르면 선택된 카드를 서버에 버리기 요청한다.
- 상점 화면에서는 보유 카드 자체를 클릭하면 뒤집기 애니메이션 중간에 서버 버리기 요청을 보낸다.
- 서버는 살아 있는 플레이어이며 현재 단계가 배틀로얄 TPS 또는 허용된 상점일 때만 버리기를 승인한다.

## 4. 현재 4·9 재경기 규칙

- 4월과 9월 조합은 카드 종류에 따라 `구사` 또는 `멍텅구리 구사`다.
- 두 카드가 모두 열(Yul) 카드면 `멍텅구리 구사`, 그 외 4·9 조합은 일반 `구사`다.
- 일반 구사: 상대 최고 패가 알리 이하일 때 재경기한다.
- 멍텅구리 구사: 상대 최고 패가 9땡 이하일 때 재경기한다.
- 멍텅구리 구사는 10땡 또는 광땡을 상대로 재경기시키지 못한다.
- 재경기에는 현재 라운드의 남은 월드 카드가 참가자 수의 두 배 이상 필요하다. 카드가 부족하면 재분배를 중단하고 현재 패로 정산한다.
- 한 번의 판정에서 재분배 시도 상한은 8회다.
- `갑오`는 합이 9끗인 일반 족보이며 재경기 특수 규칙이 없다. 현재 코드에서 갑오만으로 재경기할 수 없다.

## 작업 상세
### 1) X: 드라이브(Subst) 재부팅 유지 문제
- 현상: 재부팅 후 파일 탐색기에서 X:가 사라지고, `subst` 명령어로 확인해도 아무것도 안 뜸
- 시도: 작업 스케줄러로 트리거 설정했으나, 실행해도 매핑이 안 잡히는 문제 발생
- 해결 방향: 작업 스케줄러 대신 **배치 파일(.bat)**로 직접 실행하는 방식으로 전환

#### (중요) 배치 파일 한글/인코딩 문제
- 현상:
  - `echo off`가 `癤?echo off`처럼 깨짐
  - `문서` 경로가 `臾몄꽌`처럼 깨져서
  - `[FAIL] Target path not found` 발생
- 조치: 배치 파일 저장 인코딩/경로를 정상화한 뒤 재실행
- 결과: 배치 파일 실행 시 **X: 드라이브가 정상 생성되고 동작 확인 완료**

### 2) UE 멀티플레이 동작 확인
- 2개 화면(플레이어 2명)으로 실행했을 때,
  - 1P 화면에서 WASD 조작 시 내 캐릭터가 정상 움직임
  - 2P 화면에서 1P 캐릭터 움직임이 보임(상대가 내 주변으로 도는 것처럼 관찰)
- 결론: “기본 멀티 동작 자체는 되는 상태” 확인

### 3) 색상 변경 Replication(서버 권한) 구현 시도 (BP)
- 준비:
  - Vector Parameter 포함 Material 생성
  - Material Instance 3개(빨/초/파 등) 생성
- 구성:
  - `ColorIndex`를 RepNotify로 설정
  - `OnRep_ColorIndex` 함수(또는 이벤트)에서 `ApplyColor` 호출
  - BeginPlay에서도 `ApplyColor` 호출
  - 입력(P키) → `Server_NextColor`(Run on Server) 호출 → ColorIndex 변경 → ApplyColor로 Set Material

#### 결과/문제점
- Print String은 정상 출력됨:
  - Client/Server 호출 구분이 찍힘(예: `Server.KKK`)
- 하지만 색상 동기화가 이상함:
  - 각 화면에서 P를 누르면 **그 화면의 “자기 캐릭터”만 색이 바뀜**
  - 다른 플레이어에게는 색 변경이 반영되지 않음
- Set Material을 “모든 슬롯 반복 적용”까지 했는데도,
  - 일부(팔 등)만 색이 남거나, 기대한 전체 적용이 안 됨
- 현재 상태:
  - “RepNotify/Replicates 설정은 했는데, 서버 RPC로 바꾸는 순간 적용이 안 되거나 원격 반영이 안 되는 상태”

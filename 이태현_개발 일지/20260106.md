## 작업 상세

### 1) 목표/범위
- 목표: 로비 서버(IOCP) 기초 골자부터 먼저 완성하고, 이후에 패킷 파싱/로비 기능으로 확장
- 오늘 범위: config(일단 하드코딩) / winsock init / listen sock / iocp 생성 / worker 생성 / accept / post-recv 까지

### 2) 프로젝트 구성
- 위치: `Project-for-Graduation/Server/IOCP_Server/`
- 구성 파일:
  - `Protocol.h` : 최소 패킷 헤더 및 타입 정의(단순/직관)
  - `ServerMain.cpp` : IOCP 서버 메인 뼈대 코드

### 3) Protocol.h 작성 내용(단순화)
- PacketType(enum) 정의
- PacketHeader(size/type) 정의
- Ping/Pong 예시 구조체 추가(동작 확인용)

### 4) ServerMain.cpp 작성 내용(뼈대)
- Winsock 초기화: `WSAStartup(2.2)`
- Listen 소켓 생성/바인드/리스닝: `WSASocket → bind → listen`
- IOCP 생성: `CreateIoCompletionPort(INVALID_HANDLE_VALUE, …)`
- Worker Thread 생성: `_beginthreadex` 기반
- Accept 루프: `accept()`로 접속 수락
- Client 소켓을 IOCP에 연결: `CreateIoCompletionPort((HANDLE)clientSock, g_hIOCP, (ULONG_PTR)ctx, 0)`
- 최초 Recv Posting: `WSARecv` (Overlapped)
- 완료 처리: `GetQueuedCompletionStatus`
  - RECV 완료 시: 로그 출력 후(임시) Echo Send + 다음 Recv 재등록
  - 연결 종료/에러 시: shutdown/close 및 컨텍스트 정리

### 5) 빌드/설정 메모
- `ws2_32.lib` 링크 필요
- `winsock2.h` include는 `windows.h`보다 먼저

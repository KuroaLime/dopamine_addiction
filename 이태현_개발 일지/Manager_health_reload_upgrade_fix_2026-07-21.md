# Manager 체력 및 재장전 업그레이드 적용

작성일: 2026-07-21

## 반영 내용

- 정적 체력 업그레이드 1회당 최대 체력 증가량과 동일하게 현재 체력도 20 증가한다.
- 서버에서 체력 변경 델리게이트를 즉시 알리므로 리슨 서버 UI도 갱신된다.
- 재장전 시간 계산이 끝난 뒤 `GetFinalReloadTimeMultiplier()`를 적용한다.
- 재장전 업그레이드는 속도 배율이므로 `기본 잠금 시간 / 배율`로 계산한다.
- 비정상적으로 짧은 잠금 방지를 위해 최소 재장전 잠금 시간은 0.1초다.

## 이번 수정에서 제외한 항목

- 중앙 리스폰의 정상 경로는 현재 동작하므로 변경하지 않았다.
- 라운드별 무기 변경은 실제 실행에서 동작하므로 변경하지 않았다.
- 서버 권위 재배치 실패 처리와 중복 SpawnPointID 정리는 별도 작업으로 남긴다.

## 검증 필요

- 클라이언트와 Dedicated Server 빌드
- 체력 업그레이드 전후 현재 HP와 최대 HP가 각각 20씩 함께 증가하는지 확인
- 재장전 레벨 및 카드 업그레이드가 높을수록 사격 잠금 시간이 감소하는지 확인

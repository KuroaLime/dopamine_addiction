# Manager 섯다 초기 베팅액 동적 계산

## 요청

- 기존 고정 초기 베팅액 2골드를 제거한다.
- 해당 섯다 베팅 라운드 참가자들의 보유 골드 평균 중 10%를 초기 베팅액으로 사용한다.

## 서버 계산 방식

1. 최종 카드 제출이 끝난 뒤 실제 베팅 턴에 참가하는 유효한 PlayerState만 집계한다.
2. 각 참가자의 서버 권위 `HoldingGold`를 합산한다.
3. `총 보유 골드 / 참가자 수`를 평균 골드로 취급한다.
4. 초기 베팅액은 `총 보유 골드 * 비율 / (참가자 수 * 100)`으로 계산하고 소수점 이하는 버린다.
5. 평균 골드가 양수이고 비율도 양수인데 계산값이 0이면 최소 1골드로 설정한다.
6. 모든 참가자의 보유 골드가 0이면 초기 베팅액도 0골드다.

## 적용 범위

- 계산된 금액은 최초 Call 필요 금액으로 사용된다.
- 같은 라운드의 `삥` 및 `따당` 기준 금액에도 동일하게 사용된다.
- 라운드 초기화부터 베팅 시작 전까지 `CurrentBet`은 0으로 유지해 이전 고정 2골드가 UI에 노출되지 않게 했다.
- 서버가 팟에 넣는 `SeotdaServerSeedPot = 2`는 플레이어 초기 베팅액과 별도이므로 유지했다.

## 설정

- `MainGameMode`의 `SeotdaInitialBetPercent` 기본값은 10이다.
- 에디터 기본값에서 0~100 범위로 조정할 수 있다.

## 확인 로그

베팅 시작 시 Dedi 로그에 다음 정보가 한 번 기록된다.

`[DS] Seotda InitialBet players=... totalGold=... averageGold=... percent=10 baseBet=...`

빌드는 이 수정 작업에서 실행하지 않았다.
